# HRL · История русской литературы

Учебный сайт о Жуковском, Батюшкове и Баратынском с отдельной читалкой «Бесед о русской культуре» Ю. М. Лотмана.

Основной сайт собран из исходного архива «Жуковский и Батюшков». Читалка использует движок репозитория [«Полка»](https://github.com/mihailfedorov59042-creator/book-mixa-3/tree/ce9c1fe). Самостоятельная установка приложения и область его действия устроены по примеру [SSL](https://github.com/mihailfedorov59042-creator/SSL/tree/ac0ac50).

- `index.html` — учебные материалы и поиск по сайту и книге.
- `hrl-barat-data.js` — четыре текста Баратынского, редакторские примечания, варианты, комментарии и тезисы.
- `hrl-poem-notes.js` — заметки к полным текстам стихотворений, привязка к строкам, перенос заметок через файл.
- `reader/` — читалка, «Схема» и «Тезисы».
- `reader/data/b-lotman.js` — структурированный текст книги и координаты абзацев в источнике.
- `reader/data/lotman-theses.js` — редакторские тезисы к главам и ссылки на текст.
- `manifest.webmanifest` и `sw.js` — установка и автономное чтение.

Текст подготовлен по изданию Ю. М. Лотмана «Беседы о русской культуре. Быт и традиции русского дворянства (XVIII — начало XIX века)» (СПб., Искусство—СПБ, 1994, ISBN 5-210-01468-1). Колонтитулы и разрывы строк сняты, заголовки, абзацы, примечания и доступные подписи к иллюстрациям оформлены как текст. Для цифрового текста проведена выборочная сверка, полной корректуры не было. Схема и тезисы являются редакторскими материалами сайта.

Тексты Баратынского сверены по изображениям с. 37, 99, 109–110 и 115 издания «Стихотворения. Поэмы» (изд. подгот. Л. Г. Фризман, Наука, 1982). Номера страниц в разделе Баратынского относятся к печатному изданию. Комментарии по Семенко и Бочарову пересказаны с указанием источника.

Для локальной проверки запустите `python -m http.server 8000` в корне. После правок в опубликованных файлах запустите `python tools/build_pwa.py`, чтобы пересобрать список офлайн-ресурсов. GitHub Pages публикует корень ветки `main`. Заметки и позиция сохраняются в браузере, экспорт и импорт доступны в настройках читалки.

Рабочий промпт для следующих сайтов и книг находится в [PROMPT-STANDARD.md](PROMPT-STANDARD.md).
